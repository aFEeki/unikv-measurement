framing: 42.5 (Run-1 p0 C=1024) is ALREADY FA-off, matched to the 28.45 UniKV
arm. So the 42.5 -> 28.45 gap is ENTIRELY recall cost; there is NO FA penalty
hidden inside it. The FA-off penalty is a SEPARATE, additional layer, relative to
a vanilla FA-ON baseline:
    vanilla FA-on baseline   45.7 tok/s   (C=4096)
      -> FA-off baseline     40.1 tok/s   = 12.4% FA-off penalty (UniKV needs FA off)

So the paper's baseline comparison already controls FA (both off) and isolates
recall; the 12.4% is disclosed separately for a reader comparing UniKV against a
stock FA-on llama.cpp. Caveat: penalty measured at C=4096; the FA kernel cost
scales with context, so at C=1024 the penalty is somewhat smaller.
